# Contract: 웹 UI 화면과 실행

## 실행

```powershell
streamlit run app/main.py                                   # 로컬
streamlit run app/main.py --server.address 0.0.0.0 --server.port 8501   # 같은 네트워크 공유
$env:LH2_MODEL="models/<이름>"; streamlit run app/main.py   # 모델 지정 (기본 optimize.DEFAULT_MODEL)
```

## 공통

- 사이드바: 설계 입력 10개(학습 범위로 제한, 로그 입력 4개는 로그 눈금 select_slider), 경제 변수 5개, 세션 저장 안내 문구.
- 설계 입력 10개와 수소 가격은 슬라이더 아래에 키보드 입력칸(`num_<이름>`, 같은 범위)이 있고 서로 동기화된다. 로그 입력은 키보드 값이 정확한 값이며 슬라이더는 가장 가까운 격자로 따라간다.
- 글꼴은 맑은 고딕(화면 CSS와 Altair 그래프), 예측 탭 지표 7개는 테두리 박스.
- 탭 순서와 이름: `예측`, `비교`, `검증`, `최적화`.
- 모델 불러오기 실패: `st.error`에 경로와 원인, 이후 화면 중단.

## 예측 탭

- 잔량 곡선 차트(x: 시간 [day], y: 잔량비 [-]), 지정 기간 입력 `t_query` [day](1~365, 기본 180).
- 지표(`st.metric`): 초기 열유입 [W], `t_query`일 후 잔량비 [-], 일일 보일오프율 [%/day], 소진 시점 [day], 연간 MLI 비용·보일오프 비용·총비용 [$/yr].
- 소진 설계: `st.warning`에 소진 시점과 "비용 과소평가".
- 설계안 이름 입력 + "설계안 저장" 버튼.

## 비교 탭

- 저장 설계안이 없으면 안내. 있으면 곡선 겹침 차트, 비교 표(이름, 주요 수치, 비용), 설계안별 "삭제" 버튼.

## 검증 탭

- "ODE로 검증" 버튼 → AI·ODE 곡선 겹침, 최대 오차 [-], 365일 잔량비 오차 [-], 보일오프 비용 차이 [$/yr], 계산 시간 AI/ODE [ms].

## 최적화 탭

- 비용 분해 차트(MLI·보일오프·총비용 [$/yr] vs N), 최적 N 표시, 평평한 구간(+1%) 표시, 최적 설계 잔량 곡선.
- 지표: 최적 N [layer], 최적 총비용 [$/yr], 평평한 구간 [layer], 근사식 N* 는 ODE 검증 시 표시.
- 경고: 경계(`BOUNDARY_*`), 소진 제외 개수, 실행 가능 해 없음, 잔량 제약 활성/불가.
- 선택 제약: 잔량 목표(기간 [day], 최소 잔량비 [-]), 체적 고정(체적 [m³], 최대 직경 [m]) → 최적 L/D·N·반경 표.
- "최적 후보 ODE 검증" 버튼 → 추천 N, ODE 최적 N, 대리모델 최적 N의 ODE 총비용 상대오차 [%].
