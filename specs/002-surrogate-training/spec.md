# Feature Specification: 잔량 곡선 대리모델 학습과 평가

**Feature Branch**: `002-surrogate-training`

**Created**: 2026-11-13

**Status**: Draft

**Input**: User description: "PLAN.md 4장 대리모델 학습 단계의 요구사항과 수용 기준"

## User Scenarios & Testing *(mandatory)*

사용자는 캡스톤 개발자다. 001에서 만든 데이터셋으로 설계 입력 10개 → 365일 잔량비 곡선(100개 시점)을
즉시 예측하는 대리모델을 학습하고, ODE 대비 정확도와 속도를 평가한다. 학습된 모델은 003(최적화)과
004(웹 UI)가 쓴다.

### User Story 1 - 기본 대리모델 학습과 평가 (Priority: P1)

개발자가 데이터셋을 지정해 학습을 실행하면, 곡선 전체를 한 번에 예측하는 기본 모델이 학습되고 테스트
세트 기준 평가 보고서와 함께 저장된다.

**Why this priority**: 학습된 모델이 있어야 최적화와 UI를 시작할 수 있다.

**Independent Test**: 학습 후 저장된 모델을 다시 불러 테스트 세트를 예측하고, 보고서의 지표와 같은
값이 나오는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 001 데이터셋, **When** 기본 설정으로 학습을 실행하면, **Then** 학습·검증 손실 이력과
   테스트 세트 RMSE, R², 365일 잔량비 오차가 담긴 보고서와 모델이 저장된다.
2. **Given** 저장된 모델, **When** 테스트 세트를 예측하면, **Then** 모든 예측값이 0~1 범위에 있고
   시간에 따라 증가하지 않는다.
3. **Given** 저장된 모델, **When** 같은 입력을 대리모델과 ODE로 각각 계산하면, **Then** 대리모델이
   ODE보다 최소 100배 빠르다(배치 예측 기준).
4. **Given** 같은 데이터셋, 설정, 시드, **When** 학습을 두 번 실행하면, **Then** 테스트 지표가 같다
   (수치 연산 비결정성 허용오차 안에서).
5. **Given** 학습 범위 밖 입력, **When** 예측을 요청하면, **Then** 예측하지 않고 어떤 입력이 범위를
   벗어났는지 알린다.

---

### User Story 2 - 하이퍼파라미터 탐색 (Priority: P2)

개발자가 탐색을 실행하면 층 수, 노드 수, 학습률, 배치 크기, 가중치 감쇠를 바꿔 가며 검증 세트 오차가
가장 작은 조합을 찾고, 그 조합으로 최종 모델을 학습한다.

**Why this priority**: 목표 R² ≥ 0.99를 기본 설정으로 못 맞출 때 필요하다. 기본 모델이 먼저 있어야 비교할 수 있다.

**Independent Test**: 작은 탐색 횟수로 실행해 시도별 설정과 검증 오차 기록, 최적 조합이 남는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 탐색 횟수 지정, **When** 탐색을 실행하면, **Then** 시도마다 설정과 검증 오차가 기록되고
   최적 조합이 보고된다.
2. **Given** 최적 조합, **When** 최종 학습을 하면, **Then** 테스트 세트는 최종 평가에만 쓰이고 탐색
   중에는 쓰이지 않는다.

---

### User Story 3 - 오차 분석 보고서 (Priority: P2)

개발자는 모델이 어디서 틀리는지 확인한다. 소진 시점 근처 오차, 오차가 큰 샘플과 그 입력 영역,
탱크 크기에 따른 보일오프 비용 환산 오차를 본다.

**Why this priority**: 365일 잔량비 오차 δ는 보일오프 비용 오차 p_H2·m0·δ로 바로 이어지므로, 대형
탱크에서의 오차를 최적화 전에 알아야 한다.

**Independent Test**: 저장된 모델로 분석만 실행해 보고서가 만들어지는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 학습된 모델, **When** 오차 분석을 실행하면, **Then** 오차 상위 샘플 목록(입력·예측·정답
   곡선 그림 포함)과 입력별 오차 분포가 보고된다.
2. **Given** 소진 샘플, **When** 분석하면, **Then** 소진 시점 ±10일 구간의 오차가 따로 집계된다.
3. **Given** 기본 경제 조건, **When** 분석하면, **Then** 365일 잔량비 오차를 연간 보일오프 비용 오차
   [$/yr]로 환산한 분포가 탱크 크기별로 표시된다.

---

### User Story 4 - 데이터 수와 비교 모델 실험 (Priority: P3)

개발자는 전체 크기 1k / 5k / 10k 데이터셋(001의 부분 데이터셋, 각자 70/15/15 분할)으로 학습 곡선을 비교하고, 선택적으로 곡선 압축(주성분) + 회귀
방식과 기본 모델을 비교한다.

**Why this priority**: 발표 자료와 설계 근거에 쓰이지만 파이프라인 완성에는 필수가 아니다(헌법 원칙 VI).

**Independent Test**: 부분 데이터셋 3개로 학습해 각자의 테스트 세트 기준 지표 표가 나오는지 확인한다.

**Acceptance Scenarios**:

1. **Given** 001의 부분 데이터셋, **When** 크기별로 학습하면, **Then** 각자의 테스트 세트로 평가한
   지표 비교 표와 그래프가 저장된다.
2. **Given** 비교 모델, **When** 학습·평가하면, **Then** 기본 모델과 같은 지표, 같은 테스트 세트로 비교된다.

---

### Edge Cases

- 소진 샘플의 곡선은 0에서 꺾이는데, 모델이 이를 매끄럽게 뭉개 0 근처에서 음수나 미세한 양수를 낼 수
  있다. 출력은 항상 0~1로 제한되고 단조 비증가여야 한다.
- 로그 스케일 입력(G_sup, P_v0, G, S)은 로그 변환 후 표준화하지 않으면 작은 값 영역 정보가 사라진다.
- 데이터셋과 모델의 생성 설정(입력 범위)이 다르면 경고하거나 거부한다.
- 검증 손실이 개선되지 않으면 학습을 조기 종료하고, 가장 좋았던 시점의 모델을 저장한다.
- 학습이 발산(NaN 손실)하면 중단하고 원인 설정을 기록한다.

## Requirements *(mandatory)*

### Functional Requirements

**학습**

- **FR-001**: 시스템은 설계 입력 10개를 받아 100개 시점 잔량비 곡선 전체를 한 번에 출력하는 다층
  신경망(MLP) 기본 모델을 학습해야 한다(MUST).
- **FR-002**: 로그 스케일 입력은 로그 변환 후, 모든 입력은 학습 세트 통계로 표준화해야 한다(MUST).
  변환 정보는 모델과 함께 저장한다.
- **FR-003**: 손실 함수는 곡선 전체의 평균제곱오차이며, 검증 세트로 조기 종료와 모델 선택을 해야 한다(MUST).
- **FR-004**: 학습·검증·테스트 세트는 001 데이터셋의 분할을 그대로 쓰며, 테스트 세트는 최종 평가에만
  써야 한다(MUST).
- **FR-005**: 학습 시드를 고정·기록해야 한다(MUST, 헌법 원칙 V).

**예측**

- **FR-006**: 예측 결과는 항상 0~1 범위이고 시간에 따라 증가하지 않아야 한다(MUST).
- **FR-007**: 학습 범위 밖 입력은 예측을 거부하고 벗어난 입력을 알려야 한다(MUST, 헌법 원칙 V).
- **FR-008**: 여러 입력을 한 번에 예측하는 배치 예측을 지원해야 한다(MUST). 최적화와 UI가 쓴다.
- **FR-009**: 예측 곡선에서 365일 잔량비를 꺼내 000의 잔량비 기반 비용 계산에 바로 넘길 수 있어야 한다(MUST).

**튜닝과 비교**

- **FR-010**: 층 수(3~4), 노드 수(64~256), 학습률, 배치 크기, 가중치 감쇠를 검증 오차 기준으로
  탐색할 수 있어야 한다(MUST). 탐색 이력은 저장한다.
- **FR-011**: 001의 부분 데이터셋(전체 크기 1k/5k/10k, 각자 분할)으로 학습해 각자의 테스트 세트 지표로
  비교할 수 있어야 한다(SHOULD).
- **FR-012**: 곡선 압축(주성분 3~5개) + 회귀 비교 모델은 선택 사항이다(MAY).

**평가와 저장**

- **FR-013**: 평가 보고서는 테스트 세트 RMSE, R², 365일 잔량비 오차(평균·최대), 소진 시점 근처 오차,
  ODE 대비 추론 속도 배수를 포함해야 한다(MUST).
- **FR-014**: 오차 상위 샘플과 입력 영역 분석, 보일오프 비용 환산 오차 분포를 보고해야 한다(MUST).
- **FR-015**: 모델은 입력 변환 정보, 학습 범위, 학습 설정, 시드, 사용한 데이터셋 식별 정보, 평가
  지표와 함께 저장해야 한다(MUST).
- **FR-016**: 저장된 모델은 다른 단계에서 학습 코드 없이 불러 예측할 수 있어야 한다(MUST).

### Key Entities

- **학습 설정 (Training Config)**: 모델 구조(층 수, 노드 수), 학습률, 배치 크기, 가중치 감쇠, 최대
  반복, 조기 종료 기준, 시드, 데이터셋 식별 정보.
- **입력 변환 (Input Scaler)**: 변수별 로그 변환 여부와 표준화 통계, 학습 범위.
- **학습된 모델 (Trained Surrogate)**: 가중치 + 입력 변환 + 학습 설정 + 평가 지표.
- **평가 보고서 (Evaluation Report)**: 지표 표, 손실 이력, 오차 분석 그림, 속도 비교.
- **탐색 기록 (Tuning Study)**: 시도별 설정과 검증 오차, 최적 조합.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 테스트 세트 곡선 전체 기준 R² ≥ 0.99 (PLAN.md 8장 목표).
- **SC-002**: 테스트 세트 365일 잔량비의 평균 절대오차 ≤ 0.005, 최대 절대오차 ≤ 0.03.
- **SC-003**: 1,000개 입력 배치 예측이 ODE로 같은 1,000개를 푸는 것보다 100배 이상 빠르다.
- **SC-004**: 모든 테스트 예측이 0~1 범위이고 단조 비증가다(위반 0건).
- **SC-005**: 기본 모델 학습(탐색 제외)이 일반 노트북에서 15분 안에 끝난다.
- **SC-006**: 개발자가 평가 보고서만 보고 "최적화 단계로 넘어가도 되는가"를 판단할 수 있다
  (SC-001~004 통과 여부가 보고서 첫 부분에 표시됨).

## Assumptions

- 001 데이터셋이 생성·점검된 상태이며, 그 분할을 그대로 쓴다.
- 대리모델 입력에는 경제 변수가 없다(헌법 원칙 IV). 비용 기준 최적 N 오차는 003에서 평가한다.
- 출력은 곡선 전체(100개 값)이며, 소진 시점을 보조 출력으로 따로 학습하는 것은 SC를 못 맞출 때
  검토하는 대응책이다(PLAN.md 9장).
- 신경망 프레임워크는 plan 단계에서 정하고 근거를 기록한다(헌법 기술 제약).
- 적응적 샘플링(오차 큰 영역에 데이터 추가)은 SC를 못 맞출 때만 001로 돌아가 수행한다.
- 앙상블 기반 불확실성 정량화는 확장 아이디어로 범위 밖이다(PLAN.md 10장).
