# Feature Specification: 보일오프 물리 모델과 비용 모델

**Feature Branch**: `000-physics-cost-model`

**Created**: 2026-11-13

**Status**: Implemented (구현 후 작성한 기준 명세)

**Input**: User description: "PLAN.md 2장 물리 모델링 단계의 요구사항과 수용 기준"

## User Scenarios & Testing *(mandatory)*

사용자는 캡스톤 개발자이며, 이후 단계(데이터 생성, 대리모델 검증, 최적화 기준해, UI 검증 탭)가 모두
이 모델을 정답 기준으로 쓴다(헌법 원칙 I). 이 명세는 이미 구현된 `physics/`가 지켜야 할 기준을
기록하며, 이후 물리 모델을 바꿀 때 회귀 판단 근거가 된다.

### User Story 1 - 설계 입력으로 잔량 곡선 계산 (Priority: P1)

개발자가 설계 입력 10개(+외부 온도)를 넣으면, 횡형 캡슐 탱크에서 0~365일 동안의 액체 잔량비 곡선과
초기 열유입, 소진 시점을 얻는다.

**Why this priority**: 데이터 생성과 모든 검증의 출발점이다.

**Independent Test**: 기본 설계 입력으로 곡선을 계산해 형태(1에서 시작, 단조 감소, 0~1 범위)와
일일 보일오프율을 확인한다.

**Acceptance Scenarios**:

1. **Given** 기본 설계 입력, **When** 곡선을 계산하면, **Then** 잔량비는 1에서 시작해 단조 감소하고
   모든 값이 0~1 범위에 있다.
2. **Given** 일반적인 설계 입력, **When** 일일 보일오프율을 구하면, **Then** 0.1~2 %/day 범위에 든다.
3. **Given** 계산된 곡선, **When** 질량 감소량을 열유입 적분(∫Q_L dt / h_fg)과 비교하면, **Then**
   수치 허용오차 안에서 일치한다(질량 보존).
4. **Given** 작은 탱크와 나쁜 진공 같은 극단 조건, **When** 곡선을 계산하면, **Then** 소진 시점
   이후 잔량비는 0으로 유지되고 음수가 나오지 않는다.

---

### User Story 2 - 형상과 열유속 관계식 검산 (Priority: P1)

개발자는 탱크 형상(체적, 젖음 면적, 액위 역산)과 MLI 열유속, 진공압 식이 물리적으로 맞는지 독립
계산과 극한 조건으로 확인한다.

**Why this priority**: 형상·열유속 오류는 곡선 전체를 틀리게 만들고, 대리모델 단계에서는 찾기 어렵다.

**Independent Test**: 형상·열유속 함수만 따로 호출해 극한값과 독립 계산(단면 적분)과 비교한다.

**Acceptance Scenarios**:

1. **Given** 임의의 반경과 실린더 길이, **When** 액위 0과 만액 상태를 계산하면, **Then** 체적이 각각
   0과 전체 체적, 젖음 면적이 0과 전체 내벽 면적이 된다.
2. **Given** 액위가 반경과 같을 때(절반), **When** 체적을 계산하면, **Then** 전체 체적의 절반이다.
3. **Given** 임의의 액위, **When** 체적을 관계식과 축 방향 단면 적분으로 각각 구하면, **Then** 두 값이
   일치한다.
4. **Given** 체적에서 역산한 액위, **When** 다시 체적을 계산하면, **Then** 원래 체적과 일치한다(왕복 일관성).
5. **Given** L/D = 0, **When** 곡선을 계산하면, **Then** 같은 반경의 구형 탱크와 결과가 같다.
6. **Given** 고온·저온 온도가 같을 때, **When** 열유속을 계산하면, **Then** 0이다.
7. **Given** 다른 입력을 고정하고 하나만 바꿀 때, **When** 열유속·보일오프를 비교하면, **Then** 적층수
   N ↑ → 감소, 방사율 ε ↑ → 증가, 진공압 ↑ → 증가, 지지구조 컨덕턴스 ↑ → 증가 경향을 보인다.
8. **Given** 진공압 해석해, **When** t = 0과 t → ∞를 보면, **Then** 각각 초기 진공압과 평형압 G/S에 수렴한다.

### User Story 3 - MLI 비용과 보일오프 비용의 트레이드오프 계산 (Priority: P1)

개발자가 설계 입력과 경제 변수를 넣으면 연간 MLI 비용, 보일오프 비용, 총비용을 얻는다. 적층수를
바꿔 가며 비용 곡선을 구하고, 근사식으로 최적 적층수를 대조한다.

**Why this priority**: 최적화 단계의 목적함수이자 ODE 기준해다.

**Independent Test**: 기본 경제 조건에서 N에 따른 총비용을 계산해 U자형과 최적 N을 확인한다.

**Acceptance Scenarios**:

1. **Given** 할인율 0과 5%(수명 20년), **When** 자본회수계수를 계산하면, **Then** 각각 1/20, 0.080243이다.
2. **Given** 기본 경제 조건, **When** N에 따른 총비용을 계산하면, **Then** U자형이며 최적 N이 범위
   내부에 있고, 근사식 N* = √(B/a)와 12% 이내로 맞는다.
3. **Given** 수소 가격 ↑ 또는 수명 ↑, **When** 최적 N을 다시 구하면, **Then** 최적 N이 증가한다.
   적층 단가 ↑이면 감소한다.
4. **Given** 같은 설계, **When** ODE 경로와 잔량비 경로(365일 잔량비 → 비용)로 비용을 각각 계산하면,
   **Then** 두 결과가 일치한다.
5. **Given** 1년 안에 소진되는 설계, **When** 비용을 계산하면, **Then** 소진 표시(depleted)가 켜진다.

---

### Edge Cases

- 액위 계산 시 질량이 음수로 들어오는 경우(수치 오차)에도 0으로 처리해 형상 계산이 실패하지 않는다.
- 진공 평형압(G/S)이 초기 진공압보다 큰 경우(진공이 나빠지는 방향)도 해석해가 그대로 성립한다.
- 할인율 0에서 자본회수계수는 0으로 나누지 않고 1/Y로 처리한다.
- 소진되지 않은 설계의 소진 시점은 "소진 없음"(무한대)으로 구분된다.

## Requirements *(mandatory)*

### Functional Requirements

**형상**

- **FR-001**: 시스템은 반경 R과 실린더 길이 L로 정의되는 횡형 캡슐 탱크(양 끝 반구)의 체적, 젖음
  면적, 전체 내벽 면적, 전체 체적을 PLAN.md 2.1 관계식으로 계산해야 한다(MUST).
- **FR-002**: 시스템은 액체 체적에서 액위를 역산해야 한다(MUST). L = 0이면 구형 탱크로 동작한다.

**열유입과 지배방정식**

- **FR-003**: MLI 열유속은 Lockheed 식(Keller et al. 1974; 계수 C_s, C_r, C_g)으로 계산하며, 문헌
  단위(layers/cm, torr)로의 변환 지점을 명시해야 한다(MUST, 헌법 원칙 III).
- **FR-004**: 진공압은 아웃개싱 G, 배기속도 S, 진공 공간 체적으로 정해지는 지수 수렴 해석해로
  계산해야 한다(MUST). 진공 공간 체적은 MLI 두께(N/N̄)와 여유 간격으로 근사한다.
- **FR-005**: 액체로 들어가는 열은 젖음 면적 열 + 기상부 벽 열의 일부(η = 0.1) + 지지구조 열의
  합이어야 한다(MUST). 지지구조 열은 항상 액체로 들어간다.
- **FR-006**: 액체 질량 하나를 상태변수로 dm/dt = −Q_L / h_fg를 풀어야 하며, 소진되면 그 시점에서
  멈추고 이후 잔량비를 0으로 채워야 한다(MUST).
- **FR-007**: 출력은 지정한 기간(기본 365일)의 등간격 시점(기본 100개)에서의 잔량비이다(MUST).

**비용**

- **FR-008**: 연간 총비용 = MLI 초기비용 × 자본회수계수 + 수소 가격 × 1년 보일오프 질량으로
  계산해야 한다(MUST). MLI 초기비용 = (층당 단가 × N + 고정비) × MLI 면적(≈ 전체 내벽 면적).
- **FR-009**: 비용은 ODE를 직접 풀어 구하는 경로와, 365일 잔량비와 형상만으로 구하는 경로를 모두
  제공해야 한다(MUST). 후자는 대리모델 출력을 비용으로 바꾸는 데 쓰인다.
- **FR-010**: 적층수 목록에 대한 비용 곡선과 근사 최적 적층수 N*를 계산할 수 있어야 한다(MUST).
- **FR-011**: 1년 안에 소진되는 설계에는 소진 표시를 붙여야 한다(MUST).

**가정 (PLAN.md 2.3)**

- **FR-012**: 벤트 개방(압력 일정)을 가정하고 열성층, ortho-para 변환열, 외곽 MLI 면적 증가는
  무시한다. 이 가정을 바꾸면 PLAN.md와 이 명세를 함께 갱신해야 한다(MUST).

### Key Entities

- **설계 입력 (Design Params)**: N, N̄, ε, G_sup, P_v0, G, S, R, L/D, 충전율, 외부 온도.
- **탱크 형상 (Tank Geometry)**: R, L로부터 계산되는 체적·면적 관계와 액위 역산.
- **잔량 곡선 (Remaining Curve)**: 시점 배열과 잔량비 배열, 소진 시점.
- **경제 변수 (Cost Params)**: 층당 단가, 고정비, 수소 가격, 수명, 할인율.
- **비용 결과 (Cost Result)**: MLI 면적, 초기 질량, 1년 손실 질량, 소진 시점, MLI 초기·연간 비용,
  보일오프 비용, 총비용, 소진 여부.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: PLAN.md 2.4 체크리스트 6개 항목이 모두 자동 테스트로 확인되고 통과한다.
- **SC-002**: 설계 하나의 365일 곡선 계산이 0.1초 안에 끝난다(데이터 1만 개 생성을 수 분 안에 끝내기 위함).
- **SC-003**: 질량 보존 오차(ODE 감소량 대 열유입 적분)가 상대 0.1% 이내다.
- **SC-004**: 기본 경제 조건에서 ODE 최적 N이 적층수 범위(10~120) 내부에 있고 근사식과 12% 이내다.
- **SC-005**: 체적 관계식과 단면 적분의 상대 차이가 1e-6 이내다.

## Assumptions

- 정확도보다 경향성이 목표다. 공개 문헌 수준의 간이 모델이며 실제 업무 모델은 쓰지 않는다(헌법 보안 제약).
- 물성(h_fg 446 kJ/kg, T_c 20.3 K, ρ_l 70.8 kg/m³)은 상수로 둔다.
- 외부 온도는 기본 300 K로 고정한다.
- 이 명세는 구현 이후 작성됐다. 현재 테스트(`tests/test_physics.py`, `tests/test_cost.py`)가 수용
  시나리오를 대부분 다루며, 빠진 항목은 plan/tasks 단계에서 보강한다.
