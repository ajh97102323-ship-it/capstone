## Clarifications

### Session 2026-11-13

- Q: 1년 안에 액체가 다 증발하는 소진 샘플(약 20%)을 데이터셋에 어떻게 포함할까요? → A: 모두 포함하고, 비율은 점검 보고서로만 감시한다(덜어내기·제외 없음).
- Q: 저장소가 git으로 관리되지 않는데, 데이터셋에 기록할 "물리 모델 버전"은 무엇으로 식별할까요? → A: 물리 모델 소스 파일 내용의 해시를 자동 기록하고, 사람이 관리하는 버전 문자열도 함께 남긴다.
- Q: 요청한 샘플 수가 10,000개인데 일부가 걸러지면, 최종 데이터셋 크기를 정확히 10,000개로 채울까요, 걸러진 만큼 줄어든 채로 둘까요? → A: 줄어든 채로 둔다. 요청 수와 유효 수를 모두 기록하고, 제외 비율이 1%를 넘으면 경고한다.
- Q: 데이터 수에 따른 학습 곡선을 비교할 때, 1k / 5k / 10k는 무엇의 크기를 뜻하나요? → A: 데이터셋 전체 크기다. 전체 1k / 5k / 10k를 각각 70/15/15로 나누며, 검증·테스트 세트도 크기마다 달라진다.

## User Scenarios & Testing *(mandatory)*

이 기능의 사용자는 캡스톤 개발자(연구자)다. 개발자는 검증된 간이 물리 모델(보일오프 ODE)로
단열 설계 조합을 대량으로 시뮬레이션해, 대리모델 학습·평가에 쓸 데이터셋을 만든다. 데이터셋을
쓰는 쪽은 다음 단계인 대리모델 학습, 비용 최적화, 웹 UI 검증 탭이다.

### User Story 1 - 기본 데이터셋 한 번에 생성 (Priority: P1)

개발자가 명령 하나로 생성을 시작하면, 10개 설계 입력의 조합 10,000개를 입력 공간 전체에 고르게
뽑는다. 샘플마다 물리 모델로 0~365일 잔량비 곡선과 보조 출력을 계산하고, 비정상 샘플을 걸러낸 뒤
학습/검증/테스트 세트로 나눠 생성 설정과 함께 저장한다.

**Why this priority**: 데이터셋이 없으면 대리모델 학습, 최적화, UI 단계를 하나도 시작할 수 없다.
이 스토리만 완성돼도 다음 단계(대리모델 학습)로 넘어갈 수 있다.

**Independent Test**: 생성을 실행한 뒤 저장된 데이터셋을 열어 샘플 수, 입력 범위, 곡선 형태, 분할
비율을 확인한다. 아무 샘플이나 골라 물리 모델로 다시 계산했을 때 저장된 곡선과 일치하는지도 본다.

**Acceptance Scenarios**:

1. **Given** 물리 모델 테스트가 모두 통과한 상태, **When** 기본 설정(10,000개)으로 생성을 실행하면,
   **Then** 유효 샘플이 학습 70% / 검증 15% / 테스트 15%로 나뉘어 저장되고, 거른 샘플 수와 이유가
   요약으로 출력된다.
2. **Given** 생성된 데이터셋, **When** 샘플 하나의 입력으로 물리 모델을 다시 실행하면, **Then**
   저장된 100개 시점 잔량비 곡선과 보조 출력이 수치 허용오차 안에서 일치한다.
3. **Given** 1년 안에 액체가 다 증발하는 샘플, **When** 그 샘플의 곡선을 보면, **Then** 소진
   시점 이후 값이 모두 0이고, 소진 시점과 소진 여부가 보조 출력에 기록돼 있다.
4. **Given** 같은 설정과 같은 시드, **When** 생성을 두 번 실행하면, **Then** 두 데이터셋의 입력,
   출력, 분할이 완전히 같다.
5. **Given** 데이터셋을 만든 뒤 물리 모델 파일을 수정한 상태, **When** 데이터셋의 물리 모델 버전을
   확인하면, **Then** 저장된 해시와 현재 해시가 다르다는 사실이 표시된다.

### User Story 2 - 데이터 분포 점검 보고 (Priority: P2)

개발자는 생성이 끝난 뒤 데이터셋이 학습에 적합한지 한눈에 확인한다. 무작위 곡선 50개 겹쳐 그리기,
365일 후 잔량 히스토그램, 소진 샘플 비율, 입력별 민감도(산점도 또는 상관계수)를 담은 점검 보고서를
받는다.

**Why this priority**: 분포가 한쪽으로 몰리거나 소진 샘플이 지나치게 많으면 학습 품질이 나빠진다.
학습 전에 입력 범위를 조정할지 판단할 근거가 필요하지만, 데이터셋 자체가 먼저 있어야 한다.

**Independent Test**: 기존 데이터셋에 점검만 따로 실행해 보고서(그림과 요약 수치)가 만들어지는지,
요약 수치가 데이터셋에서 직접 센 값과 같은지 확인한다.

**Acceptance Scenarios**:

1. **Given** 생성된 데이터셋, **When** 점검을 실행하면, **Then** 곡선 겹쳐 그리기, 365일 잔량
   히스토그램, 입력별 민감도 그림과 소진 비율이 담긴 보고서가 저장된다.
2. **Given** 소진 샘플 비율이 경고 기준(30%)을 넘는 데이터셋, **When** 점검을 실행하면, **Then**
   보고서에 경고와 함께 입력 범위 조정(예: 반경 하한 상향)을 검토하라는 안내가 표시된다.
3. **Given** 점검 보고서, **When** 세트별 소진 비율을 비교하면, **Then** 학습/검증/테스트 세트의
   소진 비율이 서로 비슷하게(차이 5%p 이내, SC-006) 나타난다.

---

### User Story 3 - 설정 변경과 부분 데이터셋 (Priority: P3)

개발자는 입력 범위, 샘플 수, 시드를 바꿔 데이터셋을 다시 만들 수 있다. 학습 곡선 비교를 위해
데이터셋 전체에서 1k / 5k 크기의 부분 데이터셋을 뽑아 쓸 수 있고, 부분 데이터셋마다 학습/검증/테스트를
70/15/15로 따로 나눈다(10k는 전체 데이터셋 자체).

**Why this priority**: 점검 결과에 따라 범위를 조정하거나, 데이터 수에 따른 학습 곡선을 비교할 때
필요하다. 기본 데이터셋과 점검이 있으면 이 기능 없이도 핵심 파이프라인은 진행된다.

**Independent Test**: 범위 하나를 바꿔 생성한 데이터셋이 새 범위를 지키는지, 설정 기록에 변경이
반영됐는지 확인한다. 1k 부분 데이터셋이 5k 부분 데이터셋에 포함되는지도 확인한다.

**Acceptance Scenarios**:

1. **Given** 반경 범위를 바꾼 설정, **When** 생성을 실행하면, **Then** 모든 샘플이 새 범위 안에
   있고 저장된 생성 설정에 새 범위가 기록된다.
2. **Given** 10,000개 데이터셋, **When** 1k / 5k 부분 데이터셋을 요청하면, **Then** 전체 유효 샘플에서
   뽑히고, 작은 부분 데이터셋의 샘플은 큰 부분 데이터셋에 모두 포함되며, 부분 데이터셋마다 70/15/15
   분할이 따로 만들어진다.
3. **Given** 이전 데이터셋이 있는 상태, **When** 다른 설정으로 생성하면, **Then** 이전 데이터셋을
   덮어쓰지 않고 별도로 저장된다(명시적으로 덮어쓰기를 요청한 경우는 예외).

### Edge Cases

- 시뮬레이션이 실패하거나 결과에 NaN·음수·1 초과 값이 생기면 그 샘플을 제외하고, 제외 사유와 입력을
  기록한다. 전체 생성은 중단되지 않는다.
- 제외된 샘플이 전체의 1%를 넘으면 경고를 출력한다(물리 모델이나 입력 범위 문제일 가능성).
- 첫 시점(약 3.7일) 전에 소진되는 극단 샘플도 곡선 규칙(소진 이후 0)을 그대로 따른다.
- 적층수 N은 정수로 샘플링하므로, 범위 양 끝(10, 120)도 다른 정수와 같은 확률로 나와야 한다(단순
  반올림은 양 끝 확률을 절반으로 줄이므로 쓰지 않는다).
- 로그 스케일 변수(지지구조 컨덕턴스, 진공압, 아웃개싱, 배기속도)는 로그 공간에서 고르게 분포해야
  한다. 선형 공간에서 뽑으면 작은 값 영역이 거의 비게 된다.
- 소진되지 않은 샘플의 소진 시점은 "365일 안에 소진 없음"으로 명확히 구분해 기록한다
  (임의의 큰 숫자와 혼동되지 않게).
- 생성 도중 중단되면 불완전한 데이터셋을 정상 데이터셋처럼 남기지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

**입력 샘플링**

- **FR-001**: 시스템은 PLAN.md 3.1의 10개 입력(N, N̄, ε, G_sup, P_v0, G, S, R, L/D, 초기 충전율)에
  대해 Latin Hypercube 방식으로 입력 공간을 고르게 덮는 조합을 생성해야 한다(MUST).
- **FR-002**: 기본 샘플 수(요청 수)는 10,000개이며, 사용자가 바꿀 수 있어야 한다(MUST). 걸러진
  샘플을 채우려고 추가로 샘플링하지 않는다(MUST NOT). 최종 데이터셋 크기는 유효 샘플 수이며, 요청
  수와 유효 수를 모두 생성 요약과 생성 설정에 기록해야 한다(MUST).
- **FR-003**: 로그 스케일로 지정된 입력(G_sup, P_v0, G, S)은 로그 공간에서, 나머지는 선형 공간에서
  샘플링해야 한다(MUST).
- **FR-004**: 적층수 N은 범위 [10, 120] 안의 정수로, 모든 정수(양 끝 포함)가 같은 확률로 나오게
  샘플링해야 한다(MUST). N의 스케일은 선형·로그와 구분해 "정수"로 부른다. 외부 온도는 300 K로 고정한다.
- **FR-005**: 입력 범위는 명령줄과 설정으로, 각 변수의 스케일(선형/로그/정수)은 설정(Python API)으로
  바꿀 수 있어야 하며, 기본값은 PLAN.md 3.1과 같아야 한다(MUST). 명령줄에서 스케일을 바꾸는 기능은
  제공하지 않는다.

**시뮬레이션과 출력**

- **FR-006**: 시스템은 샘플마다 검증된 물리 모델로 0~365일 구간 등간격 100개 시점의 잔량비
  m(t)/m0를 계산해야 한다(MUST).
- **FR-007**: 액체가 다 증발한 샘플은 소진 시점 이후 잔량비를 0으로 채워야 한다(MUST). 소진 샘플은
  비율과 관계없이 모두 데이터셋에 포함하며, 덜어내거나 제외하지 않는다(MUST NOT). 비율은 점검
  보고서(FR-018~019)로만 감시한다.
- **FR-008**: 샘플마다 보조 출력 다섯 가지(초기 열유입 Q_L(0) [W], 초기 질량 m0 [kg], 365일 보일오프
  질량 m_lost [kg], MLI 면적 A_MLI [m²], 소진 시점 [day] 또는 소진 없음 표시)를 함께 저장해야 한다(MUST).
- **FR-009**: 경제 변수와 비용 값은 데이터셋에 저장하지 않아야 한다(MUST NOT, 헌법 원칙 IV).

**품질 필터링**

- **FR-010**: 시뮬레이션 실패, NaN, 음수, 1 초과 잔량비, 시간에 따라 증가하는 곡선을 가진 샘플은
  제외해야 한다(MUST).
- **FR-011**: 제외된 샘플의 입력과 사유를 기록하고, 제외 건수와 비율을 생성 요약에 표시해야 한다
  (MUST). 제외 비율이 1%를 넘으면 경고해야 한다(MUST).

**분할과 저장**

- **FR-012**: 유효 샘플을 학습 70% / 검증 15% / 테스트 15%로 무작위 분할해야 한다(MUST).
- **FR-013**: 샘플링과 분할에 쓰는 난수 시드는 고정할 수 있어야 하며, 같은 설정과 시드는 항상 같은
  데이터셋을 만들어야 한다(MUST, 헌법 원칙 V).
- **FR-014**: 데이터셋은 생성 설정(입력 범위·스케일, 샘플 수, 시드, 시간 격자, 고정값, 물리 모델
  버전 식별 정보, 생성 일시)과 함께 저장해야 한다(MUST). 물리 모델 버전 식별 정보는 두 가지다:
  ① 물리 모델 소스 파일 내용으로 자동 계산한 해시(물리 모델 파일이 한 글자라도 바뀌면 달라짐),
  ② 사람이 관리하는 버전 문자열(예: `0.1.0`).
- **FR-014a**: 시스템은 저장된 데이터셋의 물리 모델 해시가 현재 물리 모델과 다르면 이를 알려 주는
  확인 기능을 제공해야 한다(MUST). 다음 단계(대리모델 학습)가 불일치를 경고하는 데 쓴다.
- **FR-015**: 저장된 데이터셋은 다음 단계(대리모델 학습)가 입력, 곡선, 보조 출력, 세트 구분을
  추가 계산 없이 바로 읽을 수 있는 형태여야 한다(MUST).
- **FR-016**: 다른 설정으로 생성한 데이터셋은 기존 데이터셋을 덮어쓰지 않아야 하며, 덮어쓰기는
  명시적으로 요청한 경우에만 허용한다(MUST).
- **FR-017**: 생성이 중간에 실패하거나 중단되면 불완전한 결과를 완성된 데이터셋으로 남기지 않아야
  한다(MUST).

**점검과 부분 데이터셋**

- **FR-018**: 시스템은 데이터셋 점검 보고서를 만들어야 한다(MUST): 무작위 곡선 50개 겹쳐 그리기,
  365일 후 잔량 히스토그램, 소진 샘플 비율(전체·세트별), 입력별 민감도(산점도 또는 상관계수).
- **FR-019**: 소진 샘플 비율이 30%를 넘거나 365일 잔량 분포가 한쪽 끝(구간 폭 10%)에 절반 이상
  몰리면 보고서에 경고와 입력 범위 조정 안내를 표시해야 한다(MUST).
- **FR-020**: 데이터셋 전체(유효 샘플)에서 지정한 크기(예: 1k, 5k)의 부분 데이터셋을 뽑을 수 있어야
  한다(MUST). 작은 부분 데이터셋의 샘플은 큰 부분 데이터셋에 모두 포함돼야 하며(MUST), 부분 데이터셋마다
  학습/검증/테스트를 70/15/15로 따로 나누고 시드를 기록해야 한다(MUST). 부분 데이터셋의 검증·테스트
  세트는 크기마다 다르다.

### Key Entities *(include if feature involves data)*

- **생성 설정 (Generation Config)**: 데이터셋 하나를 만드는 데 쓴 모든 조건. 10개 입력의 범위와
  스케일, 샘플 수, 시드, 시간 격자(0~365일, 100개 시점), 고정값(외부 온도 300 K), 분할 비율,
  물리 모델 버전 식별 정보(소스 해시 + 버전 문자열).
- **샘플 (Sample)**: 설계 입력 10개, 잔량비 곡선(100개 값), 보조 출력 5개, 소속 세트(학습/검증/테스트).
- **제외 기록 (Rejection Log)**: 걸러낸 샘플의 입력과 제외 사유.
- **데이터셋 (Dataset)**: 생성 설정 + 세트별 샘플 + 제외 기록 + 생성 요약(유효·제외 건수, 소진 비율).
- **점검 보고서 (Inspection Report)**: 분포 그림, 요약 통계, 경고 목록. 특정 데이터셋 하나에 대응한다.
- **부분 데이터셋 (Subset)**: 데이터셋 전체에서 뽑은 지정 크기의 샘플 목록과 그 자체의 70/15/15 분할. 원본 데이터셋과 크기, 시드를
  참조한다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 기본 설정(10,000개) 데이터셋 생성이 일반 노트북 한 대에서 10분 안에 끝난다.
- **SC-002**: 유효 샘플이 요청 샘플 수의 99% 이상이다.
- **SC-003**: 무작위로 고른 샘플 20개를 물리 모델로 다시 계산하면 모든 시점 잔량비 차이가 1e-6 이하다.
- **SC-004**: 같은 설정과 시드로 두 번 생성한 데이터셋이 값과 분할까지 100% 같다.
- **SC-005**: 모든 샘플의 입력이 지정 범위 안에 있고, 각 입력을 10개 구간으로 나눴을 때 모든 구간에
  샘플이 들어 있다(로그 변수는 로그 구간 기준).
- **SC-006**: 학습/검증/테스트 세트 크기가 유효 샘플 수 기준 70/15/15% 비율과 ±1개 이내로 맞고, 세트별 소진 비율
  차이가 5%p 이내다.
- **SC-007**: 개발자가 점검 보고서 하나만 보고 5분 안에 "입력 범위 조정이 필요한가"를 판단할 수 있다.
- **SC-008**: 다음 단계(대리모델 학습)가 데이터셋을 추가 가공 없이 불러와 학습을 시작할 수 있다.

## Assumptions

- 물리 모델(`physics/`)은 이미 구현돼 있고 테스트를 통과한 상태다. 이 기능은 물리 모델의 기존 동작을
  바꾸지 않는다. 정확한 소진 시각을 돌려주는 메서드와 버전 상수만 추가하며, 기존 테스트로 동작 유지를
  확인한다(research R4, 헌법 원칙 I).
- 사용자는 개발자 한 명이며, 명령줄에서 생성과 점검을 실행한다. 웹 UI 연동은 범위 밖이다.
- 출력 시간 격자(0~365일, 100개 시점)와 입력 범위는 PLAN.md 3장 값을 기본값으로 쓴다.
- 분할은 단순 무작위 분할(층화 없음)로 하되, SC-006으로 세트별 소진 비율 균형을 확인한다. 균형이
  깨지면 그때 층화 분할을 검토한다.
- 부분 데이터셋은 전체 유효 샘플에서 시드를 고정해 뽑은 중첩(nested) 부분집합이며, 각자 따로 분할한다.
  따라서 크기별 테스트 세트가 달라, 학습 곡선 비교는 각자의 테스트 세트 지표로 한다.
- 기본 입력 범위로 2,000개를 미리 시뮬레이션한 결과 소진 비율은 약 20%, 365일 잔량비 중앙값은
  약 0.5였다. 경고 기준 안이므로 기본 범위를 그대로 쓴다.
- 소진 비율 경고 기준(30%)과 분포 쏠림 기준은 학습 품질에 대한 경험적 초기값이며, 점검 결과에 따라
  조정할 수 있다.
- 적응적 샘플링(오차 큰 영역에 샘플 추가)은 학습 단계의 리스크 대응이므로 이 기능 범위 밖이다.
- 데이터 규모(1만 개 × 약 115개 값)가 작으므로 병렬 처리는 필수가 아니다. SC-001을 못 맞출 때만 검토한다.
