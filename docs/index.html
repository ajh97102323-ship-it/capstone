액화수소 탱크 단열 설계: 적층 비용 ↔ 보일오프 손실

대리모델(MLP)로 찾은 최적 MLI 적층수를 물리 모델(ODE)로 재검증한 결과 보고서입니다. 값은 고정된 결과이며, 입력을 바꿔 보려면 Streamlit 앱(streamlit run app/main.py)을 쓰세요.

2. 경제 변수 민감도

수소 가격이 오르면 최적 적층수가 늘고, 적층 단가가 오르면 줄어든다. 근사식 N* ∝ √(p_H2 / (c_layer·CRF))와 비교.

수소 가격 → 최적 적층수

p_H2 [$/kg] 대 N* [layer]

적층 단가 → 최적 적층수

c_layer [$/(m²·layer)] 대 N* [layer]
